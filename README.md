# container-for-dev
Disposable Ubuntu image for my own personal development use

## How to use
### Windows
1. Place `ubuntu-dev.bat` somewhere and add its directory path to sysmte PATH.
2. Open or restart your terminal and type `ubuntu-dev` to start using a dedicated virtual development environment.
3. If you want to mount the current directory, please use `--mount` option and you can find the files in `/workspace/mount`.
